# USB MIDI — menu guide

Open **MIDI** in the bottom bar (phone) or navigation rail (tablet).

## Connect a controller (MIDI IN)

1. Connect a class-compliant USB MIDI controller with a USB-C/USB-OTG adapter.
2. Android may show a USB access prompt. Approve it.
3. In **MIDI IN // FROM CONTROLLER**, tap **CONNECT** next to the device.
4. Play a pad. The **MIDI MONITOR** shows `IN` messages and the drum engine responds.

The app uses the device's **output ports** as sources into the app.

## Connect a synth or interface (MIDI OUT)

1. Connect the USB MIDI destination.
2. In **MIDI OUT // TO DEVICE**, tap **CONNECT**.
3. Start the transport. Sequencer notes, clock and transport messages are sent with audio-clock timestamps.

The app uses the device's **input ports** as destinations from the app.

## Sync and routing

| Control | What it does |
| --- | --- |
| **MIDI IN** | Accept notes, CCs, clock and transport from USB. Turning it off also disables external clock follow. |
| **MIDI OUT** | Send sequencer notes and performance data to the selected output. |
| **CLOCK OUT // 24 PPQN** | Send MIDI clock while the internal transport runs. |
| **CLOCK IN // EXTERNAL SYNC** | Follow incoming clock. Play waits for the first pulse; the header shows `EXT WAIT` / `EXT LOCK`. |
| **TRANSPORT OUT** | Send start/stop when the performance transport changes. |
| **MIDI CHANNEL FILTER** | `OMNI` or a single channel 1–16. |
| **MIDI 2.0 // UMP** | Translate UMP packets for UMP-capable devices (Android 13+). Off = MIDI 1.0 byte stream. |

## Clock behavior

- Internal clock: generated by the audio engine at 24 pulses per quarter note.
- External clock: every 6 pulses advances one 16th step. Tempo is estimated from the incoming tick interval and shown in the header.
- Start (`0xFA`) resets to step 1; stop (`0xFC`) stops; continue (`0xFB`) resumes; song position (`0xF2`) moves the playhead.
- If external clock is enabled but no pulses arrive, the sequencer stays at the current step and the header shows `WAIT`.

## MIDI 2.0 / UMP

- Android 13+ exposes a UMP transport. Devices that advertise a UMP protocol are marked **UMP**.
- Incoming UMP is translated to the engine's MIDI 1.0 message model:
  - MIDI 1.0 Channel Voice (MT=2) → notes/CC
  - MIDI 2.0 Channel Voice (MT=4) → notes/CC with 16-bit velocity/value scaled to 7-bit
  - System Real-Time (MT=1) → clock/start/stop
- Outgoing notes use MIDI 2.0 Channel Voice with 16-bit velocity; clock and transport use UMP system real-time packets.
- If a device does not support UMP, leave the toggle off. The app falls back to the byte-stream ports.

UMP packet layout and device support vary by manufacturer; if a UMP device does not respond, disable **MIDI 2.0 // UMP** and reconnect.

## Note map

| Channel | Note | GM name |
| --- | --- | --- |
| BD | 36 | Bass Drum 1 |
| SD | 38 | Acoustic Snare |
| LT | 43 | Low Floor Tom |
| MT | 47 | Low-Mid Tom |
| HT | 50 | High Tom |
| RS | 37 | Side Stick |
| HC | 39 | Hand Clap |
| CH | 42 | Closed Hi-Hat |
| OH | 46 | Open Hi-Hat |
| CC | 49 | Crash Cymbal 1 |
| RC | 51 | Ride Cymbal 1 |

Alternate GM notes are also accepted (35/36 for BD, 38/40 for SD, 41/43 for LT, 45/47 for MT, 48/50 for HT, 37/75 for RS, 39/54 for HC, 42/44 for CH, 46/55 for OH, 49/52/57 for CC, 51/53/56/59 for RC). Notes 60–70 map chromatically to the 11 channels, and notes 24–34 map to the same channels one octave lower.

## MIDI CC

| CC | Target |
| --- | --- |
| 7 | Master volume |
| 74 | Master filter |
| 91 | Master reverb |
| 93 | Master delay |
| 94 | Scatter depth |
| 95 | Scatter type (1–8) |
| 20–26 | Selected channel: tune, decay, ctrl, level, pan, reverb, delay |
| 120 / 123 | All sound off / all notes off |

Program change `0–127` loads the matching kit.

## Troubleshooting

- **No device appears**: confirm the OTG adapter supports data, the controller is class-compliant, and Android's USB host feature is available.
- **Connect fails**: approve the USB prompt, then tap **CONNECT** again. The app also requests USB permission through `UsbManager` when Android has not granted it.
- **Clock drifts**: use one clock master. Disable **CLOCK OUT** if the app is following external clock.
- **Notes double-trigger**: check the controller is not sending on multiple ports; connect only the intended port.
- **UMP device silent**: disable **MIDI 2.0 // UMP**, reconnect, and verify the device's MIDI 1.0 mode.
